# 0xDMme — Licenses and distribution

## Project license

On 2026-09-30, the owner authorized distributing the frontend code under GPL-3.0, which allows keeping the Semaphore library tested in the cryptography proof. The authored code in `src/client/`, `src/shared/` and the build scripts `src/tools/build-web.ts` and `src/tools/frontend-source.ts` is available under **GPL-3.0-only**, as stated in the [full text](LICENSE-GPL-3.0.txt). The authored scripts `src/tools/frontend-vendor-source.ts` and `src/tools/frontend-matrix-source.ts`, added to the source delivery, are also GPL-3.0-only. This authorization does not relicense third-party dependencies and does not automatically grant that license to the rest of the backend or documentation.

The package is private during development. Before public distribution of the frontend, deliver the corresponding source of the exact version, including the sources, configuration and build instructions needed, with access equivalent to the distributed JavaScript/WASM. Preserve third-party notices and licenses, including Apache-2.0, MIT, BSD and MPL. Do not assume that minification, a separate Worker or an MIT license on the main package removes the obligations of GPL dependencies. See [frontend corresponding sources](docs/FRONTEND_SOURCES.md).

Private data, keys, backups, inventories and private configuration are never part of the corresponding source; they stay in ignored private directories. The software license does not require publishing conversations or secrets.
